Di gudang tempatku bekerja, barang seringkali sulit ditemukan.
Solusiku: aplikasi yang mencatat barang dan lokasinya sebagai _single source of truth._

Juga sebagai projek pertamaku di tech stack Next.js + Prisma.

Fitur:

- Form barang masuk + denah gudang
- Daftar barang dengan laman detail barang untuk melihat lokasi barang
- Barang dapat memiliki banyak lokasi dan setiap lokasi dapat diberi catatan (misal lokasi A adalah barang baru, lokasi B adalah barang lama)

## Installation

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
